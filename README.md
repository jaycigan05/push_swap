## 🧠 Algorithm

### Strategy by Input Size

* **2 elements** → simple comparison and swap
* **3 elements** → hardcoded permutations
* **4–5 elements** → push smallest to B, sort remaining, push back
* **100+ elements** → Radix Sort (bitwise)

---

### 🔍 Why Radix Sort?

* Non-comparative → efficient for integers
* Predictable operation count
* Scales well for large datasets
* Perfect for project constraints

---

### ⚡ How Radix Sort Works

1. Process numbers bit by bit (LSB → MSB)
2. For each element:

   * Bit = **1** → rotate (stay in A)
   * Bit = **0** → push to B
3. Move everything back to A
4. Repeat for all bits

## 🎁 Bonus Part

### What is checker?

The **checker** program validates whether the instructions generated by `push_swap` correctly sort the stack.

---

### How it works

* Takes same input as push_swap
* Reads instructions from stdin
* Executes operations
* Checks:

  * Stack A is sorted
  * Stack B is empty

Outputs:

* `OK` → correct
* `KO` → incorrect

---

### Example

```bash
./push_swap 4 67 3 87 23 | ./checker 4 67 3 87 23
# OK
```

---

### Why is checker useful?

* Verifies correctness
* Helps debugging
* Validates algorithm logic
* Ensures proper operation execution
